# Instruções para o Claude Code

Antes de executares qualquer tarefa, deves OBRIGATORIAMENTE seguir estes passos:
1. Identifica toda a informação em falta necessária para executar a tarefa com perfeição.
2. Faz perguntas ao utilizador até teres o contexto completo (não escrevas código sem teres a certeza do que é pedido).
3. Nunca assumas nada por ti próprio em regras de negócio ou lógica não documentada.
4. Lista quaisquer ambiguidades e pede esclarecimento antes de agir.
5. Preserva sempre a lógica existente a menos que seja explicitamente pedido para a alterar.
